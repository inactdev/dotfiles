# dotfiles

My fancy configs. Clone and change as you see fit

### NOTE: Requires Go to be installed to run fzf-lua

## Getting started

Clone the repo and run `./run.sh` (or `./run.sh bootstrap`). On an
interactive terminal with nothing remembered yet, it asks once whether
this is a home or work computer and remembers the answer for next time
(`./run.sh choose` to change it later). To skip the menu, pass a host
and/or `--no-nix` explicitly - see `./run.sh help`.

## The work host (`--no-nix`)

Home computers get the full setup via Nix + home-manager
(`flake.nix` / `home.nix` / `configuration.nix`). Corporate Macs where
Nix isn't allowed use the `work` host instead: `./run.sh bootstrap work
--no-nix` installs a smaller, captain-approved package set with plain
Homebrew and wires up configs with plain shell - no Nix, no
home-manager. Everything for that path lives under `work/`:

- `work/Brewfile` - the exact formula/cask list for the work host.
- `work/bootstrap.sh` - installs Homebrew if missing, runs
  `brew bundle`, symlinks the same `home/.config/*` and `AGENTS.md`
  files the Nix path uses (no tmux/wezterm/herdr - see below), links
  `work/zshrc` and `work/claude-settings.json` into place, configures
  git (identity is prompted for, never defaulted), and applies the
  macOS `defaults` the Nix path also sets.
- `work/zshrc` - the work host's real `~/.zshrc`. Never linked on the
  personal Mac, which gets its zshrc generated by home-manager instead.
- `work/claude-settings.json` - a work variant of
  `home/.claude/settings.json`, with the `hooks` section and
  `skipDangerousModePermissionPrompt` removed (those hooks point at a
  home-machine path and call tools not installed at work) and
  `statusLine` kept. Re-derive it after editing the source file with:
  `jq 'del(.hooks, .skipDangerousModePermissionPrompt)' home/.claude/settings.json > work/claude-settings.json`

Deliberately excluded from the work host, by captain decision: tmux,
wezterm, herdr, opensuperwhisper, docker-desktop, ollama, cloudflared,
arp-scan, imagemagick, graphviz, tree-sitter, cmake, make, watchman,
fzf, nixfmt.

Re-running `./run.sh bootstrap work --no-nix` (or `./run.sh rebuild`
once `work` is the remembered/chosen host) is safe - every step is
idempotent. The bootstrap ends with a short summary of anything it
couldn't finish (GitHub login, MDM-locked macOS settings, a still-unset
git identity).
